# Concept index

A glossary of the "big words" used in the sessions, in alphabetical order.

- [Array](array.md): A fixed-size, ordered sequence of values of the same type, accessed by index.
- [Bytecode](bytecode.md): The compact instruction format that the compiler produces and the JVM runs.
- [Compact source file](compact-source-file.md): A Java file with a main method and no class around it, run directly with java File.java.
- [Compiler](compiler.md): Translates Java source code into bytecode before the program runs.
- [Immutability](immutability.md): An immutable value cannot be changed after it is created; operations on it produce a new value.
- [JDK](jdk.md): The Java Development Kit, the tools you need to write, compile and run Java programs.
- [JIT compiler](jit-compiler.md): The part of the JVM that turns frequently used bytecode into machine code while the program is running.
- [JVM](jvm.md): The Java Virtual Machine, the program that runs Java bytecode.
- [Method signature](method-signature.md): The name of a method together with the types of its parameters; it identifies the method.
- [Overloading](overloading.md): Having several methods with the same name but different parameter types or counts.
- [Primitive type](primitive-type.md): A basic built-in type such as int or double that holds a plain value.
- [Reference vs value](reference-vs-value.md): Primitives are copied when passed around; for objects and arrays the reference is copied, so both copies point to the same thing.
- [Static typing](static-typing.md): Every variable has a type that the compiler checks before the program runs.
- [String](string.md): An immutable sequence of characters, and an object with methods.
