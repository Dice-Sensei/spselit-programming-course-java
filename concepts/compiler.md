# Compiler

Translates Java source code into bytecode before the program runs.

## How it works

The compiler reads your source code, checks it for mistakes such as type errors, and produces bytecode. If there is an error, you get a message with the line number and the program does not start. When you run `java Hello.java`, the compile step happens automatically.
