# JDK

The Java Development Kit, the tools you need to write, compile and run Java programs.

## How it works

The JDK contains the compiler (`javac`), the `java` launcher that starts the JVM, and the standard library. You install it once. With a JDK you can run a source file directly using `java Hello.java`.
