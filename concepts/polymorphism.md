# Polymorphism

One call doing different things depending on the object's actual class.

## How it works

A variable of one type can refer to objects of several related classes. When you call a method on it, the version that runs is chosen by the object that is really there, not by the variable's type. This is taught properly in S5; for now it is only a name.
