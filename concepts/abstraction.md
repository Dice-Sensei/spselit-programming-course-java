# Abstraction

Using something through what it does and not how it does it.

## How it works

You call `roll()` on a die without knowing how the number is produced. Abstraction is leaving out the details that do not matter to the caller, so the code that uses a class depends only on what it offers. Abstract classes and interfaces, which make this explicit, come in S5 and S6.
