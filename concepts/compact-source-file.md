# Compact source file

A Java file with a main method and no class around it, run directly with java File.java.

## How it works

Since Java 25, a source file may contain methods and variables at the top level, with `void main()` as the entry point. The compiler wraps them in a class for you. This keeps small programs short, and you learn classes later.
