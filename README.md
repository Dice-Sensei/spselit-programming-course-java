# Java Course

An optional, project-based Java course for students who have programmed before in any language (Python, C#, C, anything). We meet weekly. By the end of the year, you build a real project of your own choosing.

Materials are in English, because professional programming is done in English. Where a concept is easier in Czech, there is a short Czech note. The lecture itself is spoken in Czech.

## How this wiki works

- **Session pages are made of blocks.** Each block is one `##` section with its own explanation, examples and exercises.
- **Exercises come in three tiers:** *core* (everyone should do these), *extra* (more practice) and *challenge* (for strong students).
- **"→ Continued in" stubs.** If a block did not fit into a session, it moves to the next session page and the old page keeps a one-line stub pointing to it.
- **Big words link to concept pages.** The first time a term like "compiler" appears, it gets a short explanation inline and a link to its [concept page](concepts/README.md) with more depth.
- **Drop in any week.** You can skip sessions, catch up in the open lab, and leave early. Each session provides the starter code you need.

## Where to put your code

Put your own code in the `my-work/` folder. Git ignores it, so `git pull` never touches your files. Copy starter code there before editing it.
